# نور — قرآن وأذان ومواعظ

تطبيق ويب عربي بسيط وعصري يعمل على الهاتف والحاسوب، ويمكن تثبيته على الشاشة الرئيسية (PWA).

## الأقسام

- **الرئيسية**: الصلاة القادمة مع عدّاد تنازلي، التاريخ الهجري، متابعة القراءة والاستماع، وموعظة اليوم.
- **استماع**: القرآن كاملًا بأصوات ١٠ قرّاء (العفاسي، عبد الباسط، الحصري، المنشاوي، المعيقلي، السديس، الغامدي، الدوسري، العجمي، القطامي)، مع الانتقال التلقائي للسورة التالية والتحكم من شاشة القفل.
- **المصحف**: النص العثماني بخط Amiri Quran، تكبير الخط وتصغيره، الضغط على أي آية للاستماع منها أو حفظ علامة أو نسخها، وحفظ موضع القراءة تلقائيًا. السور المقروءة تُحفظ للعمل دون اتصال.
- **الأذان**: مواقيت الصلاة حسب موقعك (GPS) أو مدينتك، ١٤ طريقة حساب، ٥ أصوات للأذان، تفعيل/إيقاف الأذان لكل صلاة، وإشعارات.
- **مواعظ**: آيات وأحاديث صحيحة مصنفة مع وقفة تأملية، ويمكن نسخها ومشاركتها وحفظها.

الوضع الليلي متاح من الزر أعلى الصفحة.

## التشغيل

لا يحتاج إلى بناء. يكفي تقديم المجلد عبر أي خادم ثابت:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

ويمكن نشره مباشرة على GitHub Pages.

## مصادر البيانات

- نص القرآن: [api.alquran.cloud](https://alquran.cloud/api)
- تلاوات السور: [mp3quran.net](https://mp3quran.net)
- تلاوة الآيات: cdn.islamic.network
- مواقيت الصلاة والأذان: [aladhan.com](https://aladhan.com/prayer-times-api)

> ملاحظة: يُرفع الأذان تلقائيًا ما دام التطبيق مفتوحًا، لأن متصفحات الويب لا تسمح بتشغيل الصوت في الخلفية بعد إغلاق الصفحة.
