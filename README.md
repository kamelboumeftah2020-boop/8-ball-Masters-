# ⚽ أساطير الكرة 5×5 — Football Legends 5v5

لعبة كرة قدم أونلاين ثلاثية الأبعاد، **5 ضد 5**، كل لاعب يتحكم بنجم واحد، وتكوّنون فريقاً مع أصدقائكم.
المقاعد الفارغة يملؤها بوتات ذكية. كل الرسومات والأصوات مولّدة برمجياً — **لا توجد ملفات صور أو صوت**، فاللعبة خفيفة جداً.

## ✨ المميزات
- **9 شخصيات** لكل منها إحصائيات ومظهر و**قدرة خاصة**:
  | الشخصية | القدرة |
  |---|---|
  | 🔥 بليز | التسديدة النارية — لا يستطيع الحارس الإمساك بها |
  | ⚡ فلاش | الانطلاقة الخاطفة — سرعة خارقة 3 ثوانٍ |
  | 🗿 تايتن | الزلزال — يطيح بالخصوم القريبين |
  | ❄️ فروست | العاصفة الجليدية — تبطئ الخصوم |
  | 👤 شادو | الانتقال الآني 7 أمتار مع الكرة |
  | 🧲 ماغنيت | الجذب المغناطيسي للكرة |
  | 🐍 فايبر | الكرة الملتوية (تأثير ماغنوس) |
  | 🌩️ ثاندر | الصاعقة — تشل أقرب خصم |
  | 🛡️ غارديان | الدرع الطاقي — جدار يصد الكرة |
- **فيزياء واقعية**: جاذبية، ارتداد، احتكاك العشب، مقاومة الهواء، دوران الكرة (كرات ملتوية)، القائمان والعارضة والشباك المهتزة.
- **حركة لاعبين واقعية**: تسارع وزخم، صعوبة الانعطاف أثناء الركض، لياقة، مراوغة بلمسات، انزلاق، افتكاك، ارتماء الحارس، ضربات رأسية وتسديدات مباشرة.
- **5 ملاعب**: الملعب الملكي (نهار)، ساحة النيون (ليل)، واحة الغروب، قمة الجليد (ثلج — الكرة تنزلق)، ملعب العاصفة (مطر وبرق).
- **قواعد**: رميات تماس، ركنيات، ضربات مرمى، هدف ذهبي عند التعادل.
- **احتفالات** (1-5): زحلقة الركبة، شقلبة خلفية، رقصة، الطائرة، سيييو! + ألعاب نارية وقصاصات ملونة.
- **جمهور متحرك** يقفز ويرفع يديه ويعمل "الموجة"، **أهازيج** (أوليه أوليه، الطبول، تصفيق الفايكنغ)، أبواق، صافرة، ومعلق صوتي عربي.
- **إعادة الهدف** بالتصوير البطيء، كاميرات متعددة، شاشة عملاقة، خريطة مصغرة، إحصائيات نهاية المباراة وأفضل لاعب.
- يعمل على **الكمبيوتر والجوال** (عصا تحكم لمسية) و**يد التحكم**.

## 🚀 التشغيل
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.
- **لعب سريع**: يعمل مباشرة ضد البوتات.
- **أونلاين**: أنشئ غرفة وأرسل رابط الدعوة (أو الكود المكوّن من 5 أحرف) لأصدقائك. للعب عبر الإنترنت ارفع الخادم على أي استضافة Node.js (Render / Railway / Fly.io / VPS) — المتغير `PORT` مدعوم.

## 🌍 النشر على الإنترنت
- **Render.com**: ارفع المستودع ثم "New → Blueprint" (الملف `render.yaml` جاهز).
- **Docker** (Railway / Fly.io / أي VPS): `docker build -t fl5 . && docker run -p 3000:3000 fl5`
- اللعبة **تطبيق قابل للتثبيت (PWA)**: على أندرويد افتح الرابط في Chrome ← "إضافة إلى الشاشة الرئيسية"، فتعمل بملء الشاشة وبالوضع الأفقي، ووضع البوتات يعمل حتى بدون إنترنت.
- نسخة ملف واحد بدون خادم (ضد البوتات): `npm run build:offline` ← `dist/offline.html`.

## 🏗️ البنية
- `shared/` — المحاكاة (فيزياء، قواعد، ذكاء اصطناعي، قدرات) مشتركة بين الخادم والمتصفح.
- `server/` — خادم Node.js: ملفات ثابتة + WebSocket + غرف، محاكاة موثوقة 60Hz ولقطات 30Hz.
- `public/js/` — Three.js: الملعب، اللاعبون والحركات، المؤثرات، الصوت، الاستيفاء والتنبؤ بالحركة، الواجهة.

## 👕 نظام السكينات (للمستقبل)
الأطقم تُرسم إجرائياً كخامات في `public/js/skins.js`:
- `KITS`: أطقم الفريقين والحراس.
- `SKINS`: سكينات إضافية جاهزة (ذهبي، عسكري، كلاسيكي) — أضف عنصراً جديداً بنمط (`plain`, `pinstripes`, `stripes`, `hoops`, `sash`, `halves`, `gradient`, `camo`, `chevron`) وألوان.
- مرّر اسم السكين إلى `new Player3D(info, { skin: 'gold' })`.

## 📱 تطبيق أندرويد (APK)

التطبيق يغلّف نسخة "ضد البوتات" (تعمل بدون إنترنت) عبر Capacitor، بشاشة أفقية كاملة وزر رجوع يوقف المباراة بدل إغلاق التطبيق.

```bash
npm install
npm run build:app          # يبني dist/app/index.html
npx cap sync android       # ينسخ اللعبة داخل مشروع الأندرويد
cd android && ./gradlew assembleRelease
# الملف: android/app/build/outputs/apk/release/app-release.apk
```

يحتاج: JDK 21 و Android SDK (platform 35). حدّد مكان الـ SDK في `android/local.properties` (`sdk.dir=...`).

**التوقيع:** ضع ملف المفتاح `legends-release.jks` و `keystore.properties` داخل مجلد `android/` (لا يُرفعان إلى git أبداً).
بدونهما يُوقَّع التطبيق بمفتاح التصحيح. احتفظ بالمفتاح نفسه دائماً: التحديثات لا تُثبَّت فوق النسخة القديمة إلا إذا وُقّعت بنفس المفتاح، وهو ضروري أيضاً للنشر على Google Play.

لتغيير رقم الإصدار: `versionCode` و `versionName` في `android/app/build.gradle`.

## 🏃 اللاعبون والحركات (Motion Capture حقيقي)

- **الجسم والشعر:** [Quaternius — Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) (CC0)
- **الجري والمشي والانزلاق والسقوط والاحتفالات:** [Quaternius — Universal Animation Library 1 و 2](https://quaternius.com/packs/universalanimationlibrary.html) (CC0)
- **الركلات:** تصوير حركة حقيقي لركلات كرة قدم من [CMU Graphics Lab Motion Capture Database](http://mocap.cs.cmu.edu) (الملفات 10_02، 10_05، 11_01) — حُوّلت إلى هيكل اللاعبين بـ `scripts/retarget-cmu.mjs`.
  The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

الطقم (الألوان، الأنماط، الرقم والاسم) يُرسم على الجسم مباشرة داخل الشيدر في `public/js/player3d.js` — أي سكين جديد = بيانات في `skins.js` فقط.

لإعادة بناء `public/models/players.glb` بعد تنزيل الحزم المجانية:
```bash
CMU=/path/to/cmu ASSETS=/path/to/quaternius node scripts/retarget-cmu.mjs
ASSETS=/path/to/quaternius node scripts/build-players.mjs
```
